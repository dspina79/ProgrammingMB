---
name: create-animal
description: Adds a new class to the menagerie.py Python file that inherits from the Animal class.
---

When creating a new animal in the menagerie.py file:

1. Request the class name. This should be the type of animal.
2. Create a new class that inherits from the Animal class in the project.
3. Make the new class have the name of the animal provided.
4. Create an override of the animal_type(self) method that will return the same name as the class.

Save the menagerie.py file when done.
